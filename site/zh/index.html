Codex Skill

从痛点，做到可发布。

opc-skills 是一套面向 C 端业务研发的 Codex Skill：把用户侧 App / Web / 小程序，以及配套的 B 端运营工作台一起交付。主要给一人公司（OPC），以及必须同时交出产品与工作台的小团队用。

安装 opc-skills 打开 GitHub
v0.6.2 MIT Git · Python 3.9+

给谁用

覆盖用户侧 App / Web / 小程序 / 桌面端，配套的运营、审核、配置和客服工作台，以及背后的主 API、认证和 worker 路径。

独立开发者与一人公司（OPC）

从痛点走到可发布版本的完整路径，方法保持通用，不把私有项目细节写进 skill。

小团队

同时交付用户产品，以及让它持续运转的运营工作台：配置、审核、排错和发布控制。

以证据为准的交付

需要真实页面、真实客户端、预发、测试报告和线上回归；构建通过不能代替验收。

交付闭环

主 Agent 读取 SKILL.md，按任务进入需求验证、UI、架构、实现、测试、联调、发布或发布后内容。文章工作不阻塞页面发布。

  1. 01

    目标澄清

    先对齐用户、任务和成功路径，而不是先堆一堆字段。

  2. 02

    PRD

    写清 C 端主路径，以及这条路径要持续运转所必需的运营闭环。

  3. 03

    UI

    同时做 C 端体验和 B 端工作台原型，空态、错态和慢态不能缺。

  4. 04

    架构

    画出调用图和变更影响。客户端只打主 API，内部服务留在边界之后。

  5. 05

    实现

    从已保存的基线小步推进。项目名、账号和部署留在项目自己的事实源里。

  6. 06

    测试

    按改动文件、调用链和风险选择最小充分集合。构建通过不是证明。

  7. 07

    联调

    用真实页面和真实客户端打预发与真实 API，不能只停在登录页。

  8. 08

    发布

    预发证据、评审、发布方案签字、生产 smoke，再做固定生产域名回归。

  9. 09

    可选内容

    页面发布完成后，Content Agent 可以选题、写稿或发布中英文笔记。默认不会静默公开。

你会得到什么

可复用的方法、门禁、模板和角色占位。这不是托管运行时，也不展示私有产品截图。

  • 模板 需求验证、PRD、UI 原型、架构、变更影响、实施计划、测试策略、发布方案、证据清单、运维手册和发布后内容。
  • 角色文件 Explorer、Frontend、Backend、QA、Integration、DevOps 和 Content。skill 本身不会调用 subagent；只有你明确允许时，主 Agent 才使用运行时工具。
  • 发布完整性 配套说明和检查脚本，核对候选 commit、deployment commit、默认分支合并和 worktree 归位。
  • 一键升级 一条命令即可把已安装的 skill 升到最新版本。本地改动按受校验基线做三方合并；出现冲突时全部安装保持不变，并保留备份。
  • 安装面 CLI 提供 install、update 和 doctor，并同步 Cursor 与 Claude 发现目录。可选 Codex Agent Plugin。本仓库尚未进入公开 Plugins Directory。
  • 产品部署 本 skill 帮助交付的产品可部署到 Vercel 或 Cloudflare。平台服从项目选择；本介绍站是另一件事。

证据门禁

  1. 真实页面与客户端不是只走一遍本地 mock。
  2. 预发真实 API、存储和功能页路径。
  3. 测试报告按改动范围选择，并落盘。
  4. Code Review可评审的 diff，不是私下补丁。
  5. 发布方案签字关联系统纳入范围，或明确不发布。
  6. 生产 smoke打真实入口，而不是只看健康检查。
  7. 固定生产域名回归smoke 不能代替 P0/P1 回归。
  8. 观察窗口窗口结束前，不能宣布发布完成。

安装

需要 Git 和 Python 3.9+。一键安装会按需创建 ~/.codex/skills。安装之后，一条命令即可把已安装的 skill 升到最新版本。doctor 检查来源、版本和本地差异。

npx 
npx opc-skills install
curl 
curl -fsSL https://raw.githubusercontent.com/BiuBiuHu/opc-skills/main/scripts/install.sh | bash
升级 
npx opc-skills update

升级已有安装

npx opc-skills update 从受校验的 Git 源缓存刷新已有安装，并同步已经存在的 .agents、Cursor 和 Claude 发现目录。各安装的本地改动使用受校验基线和三方合并。任一冲突都保持全部安装不变，并保留备份。升级要你自己执行：不会在后台自动跑，也不会因为一次产品发布就覆盖全局 skill。npx opc-skills doctor 检查来源、版本和本地差异，不再要求安装目录里必须有 .git。
